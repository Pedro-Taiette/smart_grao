# Imagens de exemplo do rover simulado

As imagens `leaf-*.jpg` são do conjunto **Seasonal Corn Leaf Disease** (Mendeley Data,
https://data.mendeley.com/datasets/vy629dngm8/1), publicado sob a licença
**CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/). Autoria conforme a página do conjunto.

Alterações: redimensionadas e recodificadas pelo pipeline de preparação do SmartGrão
(`analytics/vision/manifest.py`). Todas vêm da divisão de **teste** — o modelo não as viu no treino.

`samples.json` guarda, para cada arquivo, o rótulo do conjunto (o "gabarito") e o caminho original.
São fotos de Bangladesh, não de uma lavoura do SmartGrão: a tela da simulação diz isso.
